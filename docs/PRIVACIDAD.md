# Política de privacidad de Bookhollow

Última actualización: 25 de octubre de 2026.

Bookhollow es una aplicación de organización y lectura de libros digitales. No incluye publicidad ni analítica propia, y no exige crear una cuenta. Las funciones de Google ML Kit (escáner ISBN, traducción e identificación de idioma) pueden enviar a Google datos técnicos de uso y rendimiento conforme a sus condiciones; nunca el contenido de los libros ni las notas.

## Datos que guarda

El catálogo, las portadas, el progreso de lectura, las notas, los subrayados y las preferencias se guardan en el dispositivo. Si el usuario elige una carpeta de Google Drive u otro proveedor compatible con el selector de documentos de Android, la aplicación accede solo a los archivos que el usuario autoriza, y guarda allí un archivo de respaldo de su catálogo.

Bookhollow desactiva las copias automáticas de datos de Android. La exportación y restauración de respaldos se hacen solo por decisión del usuario.

## Uso de Internet

La conexión se usa para sincronizar con el proveedor de archivos elegido y para las funciones que consultan información pública cuando el usuario las utiliza: Open Library, Wikipedia, Wikidata y Wikcionario (fichas, biografías, definiciones), la API de Google Books (datos de libros y novedades) y Project Gutenberg (clásicos gratuitos). En esas consultas se envían los términos necesarios, como el título o el autor. Para mostrar las novedades de tu país, la consulta a Google Books incluye el código del país (por ejemplo, «ES»), obtenido de la tarjeta SIM o de la región del sistema; nunca se usa la ubicación precisa. Bookhollow no tiene un servidor propio que reciba la biblioteca del usuario.

## Permisos

- Cámara: solo para escanear códigos ISBN.
- Micrófono: solo para la búsqueda por voz.
- Notificaciones y servicio multimedia: para mostrar los controles de la lectura en voz alta.
- Internet: para las consultas y sincronizaciones que inicia el usuario.

Los permisos opcionales pueden denegarse desde Android; el resto de la aplicación sigue funcionando.

## Servicios y enlaces externos

Los botones que abren otras webs (Goodreads, Casa del Libro, YouTube, la RAE…) solo las abren cuando el usuario los pulsa, y esas webs aplican sus propias políticas. La voz Davefx es opcional: Bookhollow abre la página oficial del proyecto en el navegador y no pide permiso para instalar aplicaciones.

## Control del usuario

El usuario puede exportar un respaldo, cambiar o retirar el acceso a la carpeta desde Android y borrar los datos de Bookhollow desde los ajustes del sistema. La aplicación nunca borra libros por su cuenta.
