# Política de privacidad de MiBiblioteca

Última actualización: 19 de octubre de 2026.

MiBiblioteca es una aplicación personal de organización y lectura. No incluye publicidad, rastreadores ni analítica de uso, y no exige crear una cuenta propia.

## Datos que guarda

El catálogo, las portadas, el progreso de lectura, las notas, los subrayados y las preferencias se guardan localmente en el dispositivo. Si el usuario selecciona una carpeta de Google Drive u otro proveedor compatible con el selector de documentos de Android, la aplicación accede únicamente a los archivos autorizados por el usuario.

MiBiblioteca desactiva las copias automáticas de datos de Android. La exportación y restauración de respaldos se realizan solo por decisión del usuario.

## Uso de Internet

La conexión se utiliza al sincronizar con el proveedor de archivos elegido y al solicitar funciones que consultan información pública: metadatos de libros, portadas, noticias literarias, diccionario o traducción. MiBiblioteca no opera un servidor propio que reciba el catálogo personal del usuario.

## Permisos

- Cámara: se solicita únicamente para escanear códigos ISBN.
- Micrófono: se solicita únicamente para la búsqueda por voz.
- Notificaciones y servicio multimedia: permiten mostrar y mantener los controles de lectura en voz alta.
- Internet: permite las consultas y sincronizaciones iniciadas por el usuario.

Los permisos opcionales pueden denegarse desde Android; el resto de la biblioteca seguirá funcionando, salvo la función concreta que dependa del permiso.

## Servicios y enlaces externos

Las consultas públicas y enlaces abiertos por el usuario pueden quedar sujetos a las políticas del proveedor correspondiente. La voz Davefx es opcional y su descarga se abre en el navegador; MiBiblioteca no solicita permiso para instalar aplicaciones.

## Control del usuario

El usuario puede exportar un respaldo, cambiar o revocar la carpeta autorizada desde Android y borrar los datos de MiBiblioteca desde los ajustes del sistema. La aplicación no elimina libros automáticamente durante sus tareas de mantenimiento.
