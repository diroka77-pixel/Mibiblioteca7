Política de privacidad de Bookhollow

Última actualización: 29 de octubre de 2026.

Bookhollow es una aplicación de organización y lectura de libros digitales. No incluye publicidad ni analítica propia, y no exige crear una cuenta. Las funciones de Google ML Kit (escáner ISBN, traducción e identificación de idioma) pueden enviar a Google datos técnicos de uso y rendimiento conforme a sus condiciones; nunca el contenido de los libros ni las notas.

Datos que guarda

El catálogo, las portadas, el progreso de lectura, las notas, los subrayados y las preferencias se guardan en el dispositivo. Si el usuario elige una carpeta de Google Drive u otro proveedor compatible con el selector de documentos de Android, la aplicación accede solo a los archivos que el usuario autoriza, y guarda allí un archivo de respaldo de su catálogo.

Bookhollow desactiva las copias automáticas de datos de Android. La exportación y restauración de respaldos se hacen solo por decisión del usuario.

Uso de Internet

La conexión se usa para sincronizar con el proveedor de archivos elegido y para las funciones que consultan información pública cuando el usuario las utiliza: Open Library (fichas, portadas y novedades), Wikipedia, Wikidata y Wikcionario (fichas, biografías, definiciones) y Project Gutenberg (clásicos gratuitos). En esas consultas se envían los términos necesarios, como el título o el autor. Para las novedades se envían los nombres de grandes editoriales y el idioma; el país del dispositivo se usa solo en el teléfono para elegirlas y no se envía. Bookhollow no tiene un servidor propio que reciba la biblioteca del usuario.

Permisos

  • Cámara: la app no pide este permiso. El escáner ISBN es el de Google Play services, que muestra la imagen de la cámara sin dar acceso a la app.
  • Micrófono: solo para la búsqueda por voz.
  • Notificaciones y servicio multimedia: para mostrar los controles de la lectura en voz alta.
  • Internet: para las consultas y sincronizaciones que inicia el usuario.

Los permisos opcionales pueden denegarse desde Android; el resto de la aplicación sigue funcionando.

Servicios y enlaces externos

Los botones que abren otras webs (Goodreads, Casa del Libro, YouTube, la RAE…) solo las abren cuando el usuario los pulsa, y esas webs aplican sus propias políticas. La voz Davefx es opcional: Bookhollow abre la página oficial del proyecto en el navegador y no pide permiso para instalar aplicaciones.

Control del usuario

El usuario puede exportar un respaldo, cambiar o retirar el acceso a la carpeta desde Android y borrar los datos de Bookhollow desde los ajustes del sistema. La aplicación nunca borra libros por su cuenta.

Menores

Bookhollow no está dirigida a menores de 13 años y no recoge a sabiendas datos de menores.

Cambios y contacto

Si esta política cambia, se publicará aquí con su nueva fecha. Para cualquier consulta sobre privacidad o para pedir que se retire un contenido, escribe a bookhollow.app@gmail.com.

Bookhollow privacy policy

Last updated: October 29, 2026.

Bookhollow is an app for organizing and reading ebooks. It has no ads or analytics of its own and does not require an account. Google ML Kit features (ISBN scanner, translation and language detection) may send Google technical usage and performance data under Google's terms; never the content of your books or notes.

Data it stores

The catalog, covers, reading progress, notes, highlights and preferences are stored on the device. If the user chooses a Google Drive folder or another provider supported by Android's document picker, the app only accesses the files the user authorizes, and stores a backup file of the catalog there.

Bookhollow turns off Android's automatic data backups. Backups are exported and restored only when the user decides.

Internet use

The connection is used to sync with the chosen file provider and for features that look up public information when the user uses them: Open Library (book details, covers and new releases), Wikipedia, Wikidata and Wiktionary (book details, biographies, definitions) and Project Gutenberg (free classics). These lookups send only the terms needed, such as the title or author. For new releases, the names of major publishers and the language are sent; the device's country is only used on the phone to choose them and is not sent. Bookhollow has no server of its own that receives the user's library.

Permissions

  • Camera: the app does not request this permission. The ISBN scanner is provided by Google Play services, which shows the camera image without giving the app access to it.
  • Microphone: only for voice search.
  • Notifications and media service: to show the read-aloud controls.
  • Internet: for lookups and syncs started by the user.

Optional permissions can be denied in Android; the rest of the app keeps working.

External services and links

Buttons that open other websites (Goodreads, Casa del Libro, YouTube, the RAE…) only open them when the user taps them, and those websites apply their own policies. The Davefx voice is optional: Bookhollow opens the project's official page in the browser and does not request permission to install apps.

User control

The user can export a backup, change or remove folder access from Android and delete Bookhollow's data from the system settings. The app never deletes books on its own.

Children

Bookhollow is not directed at children under 13 and does not knowingly collect data from children.

Changes and contact

If this policy changes, the new version will be published here with its date. For any privacy question or to request the removal of content, email bookhollow.app@gmail.com.
