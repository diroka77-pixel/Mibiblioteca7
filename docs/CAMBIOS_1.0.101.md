# Cambios de la versión 1.0.101 (lector de PDF)

- La página se ajusta al **ancho** de la pantalla. En horizontal queda más alta que la pantalla y
  se desplaza arrastrando hacia arriba o abajo (antes se encogía para caber entera).
- **Zoom**: pellizcar con dos dedos (de 1× a 5×) o doble toque (2,5× donde se toca; otro doble
  toque vuelve al tamaño normal). Con zoom, un dedo mueve la página; se pasa de página con los
  bordes laterales. Al cambiar de página, el zoom se reinicia.
- Las páginas se dibujan con más resolución para que el zoom se vea nítido.
- `PdfPageGeometry` limita el desplazamiento para que la página no se salga de la pantalla (con pruebas).
